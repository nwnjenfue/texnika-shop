# KUPER

## Запуск

1. Создайте в pgAdmin базу данных `kuper` (владелец — `postgres`).
2. Откройте Query Tool для базы `kuper` и выполните содержимое `schema.sql`.
3. Скопируйте `.env.example` в `.env` и укажите настоящий пароль PostgreSQL и длинный `JWT_SECRET`.
4. Выполните `npm start`, затем откройте `http://localhost:3000`.

Подключение настроено через `.env`. На этом компьютере пароль пользователя `postgres` принят экземпляром на `localhost:5433`; `5432` отвечает, но использует другие учётные данные.
